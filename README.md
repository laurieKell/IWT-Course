# IWT course

Attendee materials for the IOTC / IWT managers and scientists courses.

This repository starts as a **skeleton**. Session notebooks, data, and demos are added as each day is ready.

## Layout

| Path | Purpose |
|:---|:---|
| `Rmd/` | Worked notebooks (added per session) |
| `data/` | Small prepared inputs for the notebooks |
| `shiny/` | Interactive demos |
| `course-outline.md` | Course aims and case studies |
| `timetable.md` | Day-by-day schedule |

## Getting started

1. Clone this repository.
2. Open `IWT-Course.Rproj` in RStudio.
3. Work through the notebooks under `Rmd/` as they appear.
